### Hypridle
Config file per l'inibizione dello schermo
Si basa parzialmente sui seguenti script contenuti nella cartella Hypr/Script
 - check_audio
 - check_update
 - lock

### Hyprland
Config principale, contiene di tutto, guarda dentro che fai prima

### Hyprlock
Config file per la schermata di blocco

### Hyprlock-bg
Config file per la gestione dello sfondo della schermata di blocco
Viene aggiornato dallo script Style/Script/Update_Hyprlock, per ogni modifica utilizzare il rispettivo modulo

### Hyprpaper
Config file per lo sfondo
Viene aggiornato dallo script Style/Script/Update_Hyprpaper, per ogni modifica utilizzare il rispettivo modulo

### Monitor
Config file per i monitor che ne definisce dimensione e posizione
Viene aggiornato dal modulo Rofi/Monitor, per ogni modifica utilizzare il rispettivo modulo
