### update hyprland
Il seguente script mi genera il file colors-hyrland nella corretta cartella permettendomi di passare il colore dello sfondo ad hyprland

### update hyprlock
Il seguente script modifica il file hyprlock-bg modificando i background di hyprlock per ogni schermo

### update hyprpaper
Il seguente script modifica semplicemente il file hyprpaper.conf modificando di fatto lo sfondo dello schermo

### update sddm
Il seguente script modifica lo sfondo e lo stile del mio tema SDDM, io utilizzo il tema sugar-candy in quanto abbastanza minimale e semplice da utilizzare
Lo script utilizza un workaround che necessita di permessi SUDO, volendo tale tratto lo si può automatizzare

### update swaync
Il seguente script riscrive ogni volta tutto il file di stile di swaync modificandone i colori di base
(si, si potrebbe aggiornare il tutto creando un file apposito per swaync con solo i colori formattati bene, però devo ammettere che non ne ho voglia)
